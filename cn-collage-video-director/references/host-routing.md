# 宿主与国内软件路由

## 能力判断

按以下顺序选择最短可行路径：

| 当前能力 | 路线 | 行为 |
|---|---|---|
| 宿主有图片与视频生成插件 | 双插件生成 | 先生成无字关键帧，再逐张图生视频，保存到 `generated-clips/` |
| 宿主只有图片插件 | 图片 + 本地动效 | 生成关键帧，本地应用推镜、平移、覆盖层和转场 |
| 能使用豆包、即梦等国内工具，但没有可调用接口 | 提示词交接 | 同时生成图片与视频提示词文档，用户批量生成后放回项目目录 |
| 用户有现成素材 | 素材驱动 | 裁切、排版并生成关键帧，保留素材出处 |
| 完全离线 | 本地预览 | 用色块、图形和用户素材制作占位预览；待图片可用后替换 |

## WorkBuddy

将 Skill ZIP 作为本地 Skill 包导入。包根目录必须包含 `SKILL.md`。脚本运行需要 Python 3.10+、Pillow 和 FFmpeg；Edge TTS 是可选的联网配音组件。

WorkBuddy 能调用本机命令时，让它直接执行脚本；若当前会话没有命令执行能力，则由用户在项目目录运行文档中的命令。

## 豆包或即梦

豆包工作存在图片生成和视频生成插件时，应优先使用它们。先检查当前会话暴露的插件能力，不硬编码插件名称。图片插件负责无字关键帧；视频插件负责以该关键帧为首帧的图生视频。每个节拍独立生成，失败时只重试对应节拍。

若插件存在但当前会话不能直接调用，则生成 `image-prompts.md` 与 `video-prompts.md` 交接文件。图片提示词格式如下：

```markdown
## beat-01 — 节拍标题
用途：9:16 无字关键帧
提示词：完整中文提示词
禁止项：文字、水印、Logo、畸形手、重复主体、照片边框
输出文件：keyframes/beat-01.png
```

用户生成图片并放回指定位置后，本地渲染器继续完成字幕、配音、镜头运动和合成。若对应宿主后来提供可靠的原生图片工具，可以直接调用，但仍按相同文件名保存，保持项目可迁移。

视频提示词需写明输入图、时长、镜头、层级运动和禁止项，例如：

```markdown
## beat-01 — 图生视频
输入：keyframes/beat-01.png
时长：5 秒
提示词：镜头缓慢推进，前景纸片轻微视差，红色箭头短促移动，主体结构稳定。
禁止项：新增文字、主体变形、五官漂移、镜头旋转、闪烁、突然出现新物体。
输出文件：generated-clips/beat-01.mp4
```

## 配音替代顺序

1. Edge TTS：无需 API Key，但需要访问其语音服务。
2. 宿主或国内软件导出的中文语音：逐节拍保存到 `audio/narration/`。
3. 用户真人录音：按节拍切分，或先切分再运行渲染器。
4. Windows SAPI：仅作为机器可读的本地预览声线，正式交付前提醒用户试听。

## 安全与可迁移性

- API Key 只通过宿主密钥库或环境变量读取，不写入 JSON。
- 外部生成失败时保留已完成的脚本、提示词和素材，不从头重做。
- 所有生成结果落到项目目录，避免会话结束后丢失。
